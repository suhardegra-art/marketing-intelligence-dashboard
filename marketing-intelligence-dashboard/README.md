# Marketing Intelligence Dashboard — Personal Prototype V1

Private Next.js dashboard prototype prepared for deployment to Vercel.

Included:
- Branded login page
- Protected dashboard route
- Server-side session cookie
- Marketing overview with dummy September 2026 data
- Online/offline performance, lead funnel, top content, event highlight, and AI insight demo cards

Before deploying to Vercel, set these Environment Variables:
- DASHBOARD_EMAIL
- DASHBOARD_PASSWORD
- SESSION_SECRET

V1 intentionally does not yet include Supabase, CSV upload, real social-media APIs, or generative AI.
